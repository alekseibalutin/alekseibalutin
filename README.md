## Projects

### Smart Battery Investigator
**Java · Spring Boot · React · SQLite · OSHI · JNA**

A Windows desktop application that helps identify processes associated with excessive battery drain by comparing battery discharge with per-process CPU and memory usage.

- Collects battery and process telemetry in the background
- Stores timestamped measurements in SQLite
- Detects unusually high battery-drain periods using rolling analysis
- Ranks processes most strongly associated with high-drain intervals
- Provides a React dashboard for battery history, events, and process analysis
- Includes a mock telemetry mode for demonstrations without battery hardware

[View Project]((https://github.com/alekseibalutin/smart-battery-investigator))

### Smart Downloads
**Python · PyMuPDF · SQLite · FTS5 · Watchdog**

A local background file-management tool that automatically organizes downloads, detects duplicate files, indexes PDF contents, and keeps file operations reversible.

- Monitors the Downloads folder for newly created files
- Classifies files using filenames, file types, metadata, and PDF content
- Detects duplicates using SHA-256 hashing
- Extracts and indexes PDF text with SQLite FTS5
- Supports full-text document search from the command line
- Maintains an action history with safe undo functionality

[View Project]((https://github.com/alekseibalutin/smart-downloads))
